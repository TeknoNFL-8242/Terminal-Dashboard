# Terminal-Dashboard
Terminal Dashboard is a Go-based diagnostic and tuning tool developed for FRC roobots. It was created to optimize drive-code coefficients and improve drivers perfrmance.  Created by TEAM#8242 TeknoNFL 

You can dirrectly connect Extreme 3D Pro Joystick to your pc, get joistic output, tune your coefficient for your robots spesific requirements. We have a custom drive-algorithm for making a drive-train as smooth as possible with Joystick. You can use our drive code, at "2026RobotCodeFRC". We added a shoother calculator for 2026 FRC. So you customize this code and use as simulator/sandbox.
